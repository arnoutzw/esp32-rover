# Feature Requests

This folder contains feature request notes written from a user's perspective.

## How to Submit a Feature Request

1. Create a new markdown file with a descriptive name (e.g., `battery-low-warning.md`, `motor-control-improvement.md`)
2. Write the request from your perspective as a user - describe what you want and why
3. Include technical details if you have them, but focus on the desired outcome

## Template

```markdown
# [Feature Name]

## What I Want
Describe the feature or improvement you'd like to see.

## Why I Need It
Explain the problem this solves or the value it adds.

## How I Imagine It Working
Describe the expected behavior from a user perspective.

## Technical Notes (Optional)
Any technical constraints, preferences, or implementation ideas.
```

## Processing

When an AI assistant sees a feature request in this folder, it will:

1. Analyze the request and extract requirements
2. Create or update requirements in `docs/requirements/`
3. Present the proposed changes for review
4. Once approved, the feature request can be archived or deleted
